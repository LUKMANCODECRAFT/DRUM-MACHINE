A modern, responsive, and feature-packed web-based **Digital Drum Machine & Audio Sequencer** built with HTML5, Vanilla CSS3 (Glassmorphism & Neon Studio Aesthetics), and JavaScript (Web Audio / HTML5 Audio API).

Developed by **[lukmancodecraft](https://github.com/lukmancodecraft)**.

---

## 🌟 Key Features

- **🎛 Master Studio Controls**:
  - **Power Switch**: Realistic ON/OFF hardware toggle with LED indicator.
  - **Master Volume**: Smooth dynamic slider with percentage display and one-click mute button.
  - **BPM Tempo Control**: Adjustable tempo slider (60 – 180 BPM) for sequence playback.

- **🎹 Dual Sound Kits (Sound Banks)**:
  - **Kit 1 (Heater & Acoustic)**: Classic drum kit with punchy kicks, snares, claps, and open/closed hi-hats.
  - **Kit 2 (Synth & Percussion)**: Electronic chords, shakers, side sticks, and synth drum sounds.

- **🔴 Pattern Recorder & Loop Playback**:
  - **Real-time Recording**: Capture live beat sequences with exact timestamp precision.
  - **Looping Engine**: Toggle continuous loop playback.
  - **Preset Rhythm Patterns**: Quick-load pre-programmed beats (*Hip-Hop*, *House*, *Rock*).

- **📊 Dynamic Audio Equalizer Visualizer**:
  - HTML5 Canvas visualizer providing live visual frequency bar feedback whenever pads are triggered.

- **💻 Cyberpunk / Studio Hardware Aesthetic**:
  - Glassmorphism chassis, retro LCD synth readout, glowing neon LED lights, Google Fonts (`Orbitron` & `Inter`), and active keypress press animations.

## ⌨️ Keyboard Shortcuts & Trigger Map

You can trigger drum pads using either your mouse/touchscreen or keyboard shortcuts:

| Key | Sound Kit 1 (Heater) | Sound Kit 2 (Synth & Perc) |
| :---: | :--- | :--- |
| **Q** | Heater 1 | Chord 1 |
| **W** | Heater 2 | Chord 2 |
| **E** | Heater 3 | Chord 3 |
| **A** | Heater 4 | Shaker |
| **S** | Clap | Open HH |
| **D** | Open HH | Closed HH |
| **Z** | Kick 'n Hat | Punchy Kick |
| **X** | Kick | Side Stick |
| **C** | Closed HH | Snare |
| **Space** | Play / Stop Sequence Loop | Play / Stop Sequence Loop |
| **R** | Toggle Beat Recording | Toggle Beat Recording |

## 🚀 Quick Start & Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/lukmancodecraft/DRUM-MACHINE.git
   cd DRUM-MACHINE
   ```

2. **Run locally**:
   - Open `index.html` directly in any web browser (Chrome, Firefox, Edge, Safari).
   - Alternatively, serve via VS Code Live Server or static server.
